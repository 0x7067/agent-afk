test(whatif): extend calibration harness — Beta latent, tau dimension, updated thresholds

Replace the clamped-Normal latent with a Beta distribution parameterised by
(mean, ICC) so no probability mass piles up at 0 or 1, eliminating the ~21%
at-boundary artefact that mechanically suppressed false confirms and partially
masked the Monte Carlo symptom of #2404.

Add a tau (effect-heterogeneity) dimension: per-episode delta_e ~ Normal(delta, tau).
When tau > 0 AND ICC is high, pooling correlated samples overstates precision more
acutely than in the homogeneous-effect case.

Key harness changes:
- betaFromICC(): derive Beta(alpha, beta) from target mean and ICC
- betaSample(): Johnk's method (alpha, beta >= 0.5 by construction)
- tau now a grid axis alongside trueDelta x episodes x samples
- findCell() takes an optional tau argument (default 0)
- renderMarkdownTable() accepts includeTau flag
- LOW_ICC_SD / HIGH_ICC_SD kept as deprecated aliases
- NEW: LOW_ICC = 0.083, HIGH_ICC = 0.390 (ICC-valued constants)

Test updates:
- Replace it.fails with plain it for tests that now pass (power thresholds
  updated to reflect the corrected per-episode analysis -- old thresholds were
  inflated by n-inflation from #2404)
- Add section 7 (false-confirm across ICC/tau) and section 8 (false-refute with tau>0)

Refs #2404 #2405 #2415
